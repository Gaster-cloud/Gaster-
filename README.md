# 猜数字游戏（Guess Number）

一个用 Python 编写的命令行小游戏：电脑随机想一个数字，玩家来猜，猜错会提示"大了"或"小了"，在规定的次数内猜中即获胜。

## ✨ 功能特性

- **三种难度**：简单 / 普通 / 困难，数字范围和猜测次数各不相同
- **实时提示**：每次猜测后提示"猜大了"或"猜小了"，并显示剩余机会
- **输入校验**：输入非数字或超出范围的内容不会崩溃，会友好提示重新输入
- **多局对战**：一局结束后可选择继续挑战，退出时统计总局数和胜局数
- **零依赖**：只用 Python 标准库，无需安装任何第三方包

## 🚀 怎样运行

### 准备工作

1. 安装 [Python](https://www.python.org/downloads/)（3.8 或更高版本均可）
2. 下载本项目：

   ```bash
   # 方式一：用 git 克隆（推荐）
   git clone https://github.com/Gaster-cloud/guess-number.git

   # 方式二：在 GitHub 网页上点 Code -> Download ZIP，解压即可
   ```

### 运行游戏

打开命令行（Windows 上为 CMD / PowerShell / 终端），进入项目文件夹，执行：

```bash
python guess_number.py
```
